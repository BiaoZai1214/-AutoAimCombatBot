# 自瞄步战车 — 项目总览 & 快速入门

## 一句话概括

麦轮底盘 + 二自由度云台 + 视觉追踪 = 能全向移动、遥控驾驶、自动瞄准的机器人小车。

## 快速入门（30分钟看懂整个项目）

### 第1步：看 main 函数（5分钟）

打开 `Core/Src/main.c` → `main()`：
```
HAL_Init → 时钟配置 → GPIO/USART/SPI/TIM/I2C 初始化
    → MX_GPIO_UserInit (自定义初始化)
    → SPI_LCD_Init, Servo_Init, Robot_Init
    → freertos_start()  // 启动调度器，不再返回
```

### 第2步：看 FreeRTOS 任务入口（5分钟）

打开 `Core/Src/freertos.c` → `freertos_start()`：
```
xTaskCreate(Control_Task)  ← 底盘+舵机+LCD, 20ms循环
xTaskCreate(W5500_Task)    ← 以太网初始化
xTaskCreate(LED_Task)       ← 心跳灯
vTaskStartScheduler()
```

### 第3步：看主控制循环（10分钟）

打开 `App/ui.c` → `Control_Task()`：
```
开机自检 (电机转0.3s) →
  for(;;) {
    1. PS2_Scan        → 读取手柄
    2. PS2_DriveControl→ 摇杆→目标速度
    3. Robot_Kinematics → 运动学+PID+输出
    4. Tracking_Update  → 视觉追踪
    5. 电池刷新         → 每分钟一次
    6. vTaskDelay(20ms) → 控制频率50Hz
  }
```

### 第4步：看运动学核心（10分钟）

打开 `App/robot.c` → `Robot_Kinematics()`：
```
ReadEncoders         → 读4路编码器
ForwardKinematics    → 轮速 → 底盘速度
ClampTarget          → 目标限幅
InverseKinematics    → 底盘目标 → 各轮目标
PID_Update           → PD控速 → TB6612.SetSpeed
```

## 关键数字速记

| 数字 | 含义 |
|------|------|
| 20ms | 控制循环周期 (50Hz) |
| 50Hz | 舵机 PWM 频率 |
| 20kHz | 电机 PWM 频率 |
| 1560 | 编码器分辨率 (13线×30减速比×4倍频) |
| 3 | FreeRTOS 任务数 (Control + W5500 + LED) |
| 400MHz | CPU 主频 (HSE 25MHz × 32 / 2) |
| 100kHz | I2C1 通信速率 (ESP-S3) |
| 0x52 | ESP-S3 I2C 从机地址 |

## 两个指南的阅读顺序

1. **先读底盘** — 因为底盘是项目的基础，PS2控制、运动学、PID 都在里面
2. **再读自瞄** — 舵机控制相对独立，但追踪模式切换时需要理解 PS2 按键处理

两个系统通过 `Control_Task` 的 20ms 循环联动：
- 每帧先处理底盘（PS2 → 运动学 → 电机）
- 再处理自瞄（I2C 读 ESP → 写舵机）
- 互不阻塞，各自独立运行
